Sauvegarde cloud

Code accepté

La Protection avancée des données exige l'accès Web. Sur l'iPhone, ouvrez Réglages > compte Apple > iCloud, activez Accès aux données iCloud sur le Web, puis approuvez la demande Apple éventuelle.

Session Apple incomplète

Apple a accepté le code mais n'a ouvert qu'une session partielle. Connectez-vous à iCloud.com et acceptez les nouvelles conditions éventuelles avant de relancer.

Ouvrir iCloud.com

Étape 1 : saisissez Apple ID et mot de passe, puis connectez. Étape 2 : quand Apple affiche le code sur votre appareil, AI Memory montre le champ de confirmation. Les mots de passe spécifiques d'app ne sont pas acceptés par iCloud Drive. Pour utiliser le compte iCloud déjà connecté à macOS, choisissez iCloud Drive du Mac.

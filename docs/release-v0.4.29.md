# AI Memory v0.4.29

## Français

- Ajoute une icône AI Memory dans la zone de notification Windows, avec l'état du watcher, le dernier scan et l'état du cloud.
- Permet d'ouvrir l'interface ou le dossier des conversations et de quitter uniquement l'interface depuis cette icône.
- Active le lancement automatique de l'icône à la connexion Windows depuis le réglage existant.
- Supprime la fenêtre de terminal `cmd` lors du lancement de l'application graphique Windows.
- Embarque un utilitaire console séparé et testé pour préserver le watcher et le MCP.

## English

- Adds an AI Memory icon to the Windows notification area with watcher, latest scan, and cloud status.
- Opens the dashboard or conversation folder and quits only the interface from the tray menu.
- Supports starting the tray icon at Windows sign-in through the existing setting.
- Removes the `cmd` terminal window when launching the Windows graphical application.
- Bundles and tests a separate console helper so watcher and MCP behavior remains intact.
